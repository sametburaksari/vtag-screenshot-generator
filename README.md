# vTag Screenshot Generator

App Store ve marketing materyalleri için screenshot oluşturucu. Next.js ile geliştirilmiştir.

## Kurulum

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Klasör Yapısı

```
├── app/                 # Next.js app router
├── public/
│   └── screenshots/     # Oluşturulan screenshotlar
└── ...
```

## Teknolojiler

- [Next.js 14](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
